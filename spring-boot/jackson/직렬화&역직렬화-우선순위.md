## 매핑 대상 지정 우선순위
Jackson은 데이터를 매핑할 때 다음 순서대로 속성을 찾습니다.

1. **`@JsonProperty` (가장 높음):** 필드, 게터(Getter), 세터(Setter)에 직접 붙은 애노테이션이 최우선입니다.
2. **`@JsonGetter` / `@JsonSetter`:** 게터/세터 메서드에 붙은 애노테이션입니다.
3. **Getter/Setter 메서드:** 애노테이션이 없다면 메서드 이름(예: `getName()`, `setName()`)을 기준으로 매핑합니다.
4. **필드(Field) 이름:** 게터/세터가 없는 경우 필드명을 기준으로 매핑을 시도합니다.

> 핵심 팁: 게터(getAge())가 존재하면 Jackson은 기본적으로 필드(private int age)보다 게터를 우선하여 사용하여 값을 가져옵니다.

## 역직렬화(JSON -> 자바 객체) 시 우선순위
JSON 데이터를 자바 객체로 변환할 때의 우선순위입니다.

1. **`@JsonCreator` (생성자/팩토리 메서드):** 가장 높은 우선순위로, 매개변수가 있는 생성자를 통해 객체를 생성합니다.
2. **`@JsonProperty` (필드/setter):** 생성자 이후에 필드나 세터에 `@JsonProperty`가 있다면 매핑합니다.
3. **Setter 메서드:** `setXXX` 형태의 메서드를 사용하여 값을 설정합니다.
4. **필드 직접 매핑:** 세터가 없으면 `private` 필드라도 직접 접근하여 값을 설정합니다.

## 직렬화(자바 객체 -> JSON) 시 우선순위
자바 객체를 JSON으로 변환할 때의 우선순위입니다.

1. **`@JsonValue`:** 객체 전체를 하나의 값으로 직렬화할 때 사용합니다.
2. **`@JsonProperty` (Getter/Field):** 게터나 필드에 붙은 애노테이션입니다.
3. **Getter 메서드:** `getXXX()` 또는 `isXXX()` 메서드를 통해 값을 읽어옵니다.
4. **public 필드:** Getter가 없으면 public 필드를 사용합니다.

## 기타 주요 우선순위 설정
- **이름 매핑:** `@JsonProperty("newName")`은 자바 필드명보다 우선합니다.
- **별칭 매핑:** `@JsonAlias`는 역직렬화 시 `@JsonProperty`와 함께 사용하여 여러 다른 JSON 키 이름을 받을 때 사용됩니다.
- **필드 순서:** `@JsonPropertyOrder({ "id", "name" })`를 클래스에 설정하여 JSON 출력 순서를 정의할 수 있습니다.

요약하자면, Jackson은 `getter/setter` 기반의 Bean 규약을 기본으로 하되, `@JsonProperty` 애노테이션이 붙은 곳을 가장 우선적으로 매핑합니다.
