프로퍼티 빈의 프로퍼티에 값을 설정할 때 빈의 후처리기, BeanPostProcessor를 사용할 수 있다. 이 방법을 사용하면 빈의 프로퍼티를 동적으로 설정할 수 있게 되어 하나의 빈 후처리기로 다수의 프로퍼티 빈의 값을 외부 설정으로부터 주입시킬 수 있다. 

1. 프로퍼티 빈의 값 설정을 처리할 방법으로 빈 후처리기를 사용할 클래스를 구분할 마커 애노테이션을 정의한다.
   1. 마커 애노테이션을 구현한 클래스는 `@Component` 애노테이션을 메타 애노테이션으로 사용하여 스프링 빈으로 만든다.
   2. 마커 애노테이션의 파라미터로 접두사를 받을 수 있도록 만든다.
      1. 접두사는 프로퍼티가 사용될 수 있는 갈래에 따라 고유한 프로퍼티로써 구분지어질 수 있게 한다.
         1. e.g) `server.port`, `database.port`
2. 빈 후처리기에서 해당 마커 애노테이션이 붙은 빈의 후처리를 작성한다.
   1. 해당 마커 애노테이션이 사용된 빈(= 프로퍼티 빈)을 필터링한다.
   2. 스프링이 제공하는 바인더 클래스와 구성 정보 클래스를 사용해 빈의 프로퍼티를 주입하는 후처리를 작성한다.
3. 해당 빈 후처리기를 자동 구성 정보에 추가한다.
4. 처리돈 프로퍼티 빈을 사용하는 클래스에서 어떤 프로퍼티 빈을 사용할지 선택할 마커 애노테이션을 정의한다.
   1. 해당 마커 애노테이션이 어떤 프로퍼티 빈을 처리할지 동적으로 결정할 수 있도록 파라미터를 생성해준다.
      1. 정해지지 않은 타입 값을 파라미터로 받을 수 있도록 `Class<?>` 타입의 파라미터(`value`)로 선언해준다.
   2. 해당 마커 애노테이션이 `value` 값을 읽어서 프로퍼티 빈을 import할 수 있도록 `ImportSelector` 구현체를 작성한다.
   3. `ImportSelector` 구현체를 해당 마커 애노테이션에 `@Import` 시칸다.
