/oh-my-claudecode:team N:agent-type "task description"

- 짧게: /team N:agent-type "..." (별칭이 작동)
- N = 워커 수 (1~20, 생략 시 자동)
- agent-type 생략 가능 — 생략하면 lead가 단계별로 알아서 선택
- ralph 모디파이어를 더하면 Ralph 영속 루프로 감쌈: /team ralph "..."

예:
/team 3:explore "verify maintainer's doc changes and hunt residual drift for #6036"
/team 4:executor "fix all TS errors in src/"
/team "refactor auth module"   # agent-type 자동

알아둘 함정 하나

N:agent-type은 team-exec 단계 워커만 지정한다. 다른 단계(plan/prd/verify/fix)는 lead가 stage routing 표에 따라 자동 선택한다(예: verify에는 verifier, 큰 변경엔 code-reviewer+security-reviewer가 자동 추가). 즉 우리 #6036
응답 준비처럼 "검증 + drift 사냥"이 본질인 작업이면 굳이 agent-type을 강제 지정 안 해도 lead가 알아서 explore/verifier를 호출한다. 명시적으로 explore를 박고 싶으면 N:explore로 주면 된다.
