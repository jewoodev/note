# 값 타입 컬렉션 
값 타입을 하나 이상 저장하려고 하면 그걸 컬렉션에 보관하고 `@ElementCollection`과 `@CollectionTable`을 사용하면 된다.

여기서 중요하게 짚고 넘어가고 싶은 건 값 타입 필드와 값 타입 컬렉션이 있는 엔티티를 조회했을 때 페치 전략이 어떻게 적용되는지이다. 기본적으로 값 타입 필드는 엔티티에 하나가 있으므로 즉시 로딩, 컬렉션은 일대다 관계이므로 지연 로딩이 기본이다. 하지만 `@ElementCollection`에 `fetch = FetchType.EAGER`를 설정하면 즉시 로딩이 가능하다.
