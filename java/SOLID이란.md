SOLID는 객체 지향 프로그래밍에서 유지보수하기 좋고 유연한 소프트웨어를 만들기 위한 다섯 가지 설계 원칙의 앞 글자를 딴 것입니다.

첫째, 단일 책임 원칙(SRP)은 하나의 클래스는 하나의 책임만 가져야 한다는 뜻이에요. 

둘째, 개방-폐쇄 원칙(OCP)은 기존 코드를 수정하지 않고도 기능을 확장할 수 있어야 한다는 의미입니다. 

셋째, 리스코프 치환 원칙(LSP)은 자식 클래스는 언제나 부모 클래스를 대체할 수 있어야 한다는 내용이고, 

넷째, 인터페이스 분리 원칙(ISP)은 자신이 사용하지 않는 기능에 의존해서는 안 된다는 뜻입니다. 

마지막으로, 의존관계 역전 원칙(DIP)은 세부적인 것보다 추상적인 것에 의존해야 한다는 원칙이에요.

컴퓨터를 조립하는 것에 비유할 수 있어요. 마우스는 '입력'이라는 하나의 책임만 지고(SRP), USB 포트에 키보드 대신 새로운 마우스를 꽂아도 잘 동작하며(OCP, LSP), 마우스에 불필요한 프린터 기능이 포함되어 있지 않죠(ISP). 그리고 컴퓨터는 특정 '삼성 마우스'가 아닌 'USB 입력 장치'라는 표준에 의존하기에 어떤 마우스든 연결할 수 있습니다(DIP).
