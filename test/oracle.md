"오라클(oracle)"은 테스트 용어야 — *"어떤 결과가 옳은지(pass/fail)를 판정해주는 기준 / 진실의 출처"*를 뜻해. 정식 용어로 test oracle.

내가 쓴 **"stash 오라클"**의 의미:
- git stash로 내 변경을 잠깐 치워 clean 상태를 만든 뒤 같은 테스트를 돌리면, 그 결과가 *"이 실패가 내 변경 때문인가?"*를 판정하는 기준(oracle) 이 돼.
    - 변경을 치웠는데도 똑같이 실패 → 내 변경은 범인 아님 (pre-existing).
    - 치우니까 통과 → 내 변경이 회귀의 원인.
- 즉 stash가 "내 코드가 범인인지"를 가려주는 대조군/판정자 역할이라 그렇게 부른 거야.
